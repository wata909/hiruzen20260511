# 蒜山 フィールド地図

https://wata909.github.io/hiruzen20260511/

蒜山のCS立体図（`tiles/`）に、地理院地図・主題図・GNSSログ・範囲保存（オフライン）を組み合わせたスマホ向けWeb地図（PWA）。
本体は [wata909/fieldmap](https://github.com/wata909/fieldmap) を移植したもの。

iPhone の Safari で開き「ホーム画面に追加」すると、アプリのように使えます。現在地・GNSSログには HTTPS での公開が必要です（GitHub Pages は HTTPS）。

## 画面下のツールバー
- **地図**：背景（標準・淡色・写真）＋ 地形（CS立体図・陰影起伏・色別標高）＋ 主題図1つ（地質・植生・地形分類・古写真）＋ 重ねるデータ（GNSSログ・筆ポリゴン・人口・旧市町村界・読込データ）
  - CS立体図は通常の重ね方、陰影起伏・色別標高は乗算で主題図の上に重なる
- **現在地**：現在地を表示し続ける
- **記録**：GNSSログの開始／停止、軌跡表示、GPX・GeoJSONで保存、消去
  - 記録は端末内（localStorage `hiruzen-gnss-log-v1`）に残る。旧版の記録もそのまま読み込まれる
  - iPhoneでは画面が消えると記録が止まるため、記録中は画面ロック防止（Wake Lock）をかける
- **集水域**：💧を押して地点をタップ → 地理院DEM（10m）から上流の集水域を計算
- **保存**：今の画面の範囲を端末に保存（圏外で使えるように）。CS立体図タイルも保存できる
- **その他**：共有URL、文化財総覧WebGISへのリンク、GeoJSON読込、ZIP書き出し（GNSSログも入る）、出典

共有URL例：`#map=14/35.30819/133.59993&b=seamlessphoto&o=cs:0.9&v=gnss`

## ローカルで試す
```
python3 -m http.server 8000
```

## 出典
- CS立体図：GeoTIFFから作成したタイル（`tiles/`）
- 地理院タイル（国土地理院）
- 地質図：産総研地質調査総合センター「20万分の1日本シームレス地質図V2」（CC BY 4.0）
- 植生図：環境省生物多様性センター「現存植生図2024」
- 旧市町村界：歴史的行政区域データセットβ版（CODH）
- 筆ポリゴン：農林水産省「筆ポリゴンデータ（2022年度公開）」（農研機構 FlatGeobuf版）
- 人口：総務省統計局 国勢調査 地域メッシュ統計（e-Stat, 令和2年 500m）
